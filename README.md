# FamCart – Shop Smart Together 🛒

## About the Application
FamCart is a family shopping list organizer that helps users manage their grocery items and shopping activities. It allows families to organize products by category, monitor expenses, and track purchased items.

## Features
- Dashboard for shopping statistics
- Create and manage shopping lists
- Add products with quantity and price
- Organize products by category
- Track purchased and pending items
- Monitor shopping budget and expenses
- Family member management
- Shopping history
- Responsive and user-friendly design
- Local storage for saving data in the browser

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code

## How to Install and Run
1. Download or clone this repository.
2. Extract the ZIP file.
3. Open the FamCart folder in Visual Studio Code.
4. Install the Live Server extension.
5. Open `index.html`.
6. Right-click and select Open with Live Server.
7. The application will open in your browser.

## How to Use
1. Open the FamCart application.
2. Create a shopping list.
3. Add products with their names, quantities, prices, and categories.
4. View your products in the Categories section.
5. Mark items as purchased when shopping.
6. Monitor your budget and shopping progress through the dashboard.
